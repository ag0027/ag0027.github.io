01 — WHERE I WENT

I used to
build things.

Desktop software, mostly. C# and WPF — drag a control onto the canvas, set its properties, wire up an event handler. It worked. I was decent at it.

Then life took the keyboard away for about five years. Long enough for the tools to move on without me. Long enough to start wondering whether the part of my brain that did this still worked at all.

It does. It's rusty. Rust is fine — rust comes off.

02 — WHAT CHANGED

Beginner
again.

Starting over is a strange feeling when you weren't always a beginner. Kotlin sits close enough to what I knew that it reads familiar, and far enough away that I trip over it constantly.

But the language isn't the real shift. WPF was imperative — I told the interface what to do, and it sat there until I told it something else. Compose is declarative: I describe what the screen should be for a given state, and it works out the rest.

That's a rewiring, not a rename. So I'm taking it slowly. Small programs. Things that actually run.

03 — LOADOUT

Equipped.

KOTLIN JETPACK COMPOSE
C# WPF

Kotlin now, Compose next. The old gear stays in the bag — five years out of date, but the instincts underneath it didn't expire.

One rule I keep: write something from an empty file before I look anything up. Even ten minutes of it. Reading code and producing code are different muscles, and only one of them gets built by watching.

04 — CURRENTLY

Building
something small.

Nothing clever. A timer app, put together with XML layouts — not because XML is the right long-term answer, but because it's what clicked first, and getting something onto a screen beat waiting until I understood the elegant version.

That's the whole method. Ship the ugly one. Then ship a better one. Perfect is a thing you arrive at from behind, never a thing you start with.

Name unlocks when it's finished.
